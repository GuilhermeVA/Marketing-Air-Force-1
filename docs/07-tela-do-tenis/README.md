# Feature: Tela do tênis

**Criada em:** 2026-11-14

## Objetivo

Ao tocar num par do closet, abrir uma tela só com ele: se desbloqueado, carrossel no estilo e-commerce, palavras-chave da cor e o texto de significado (a cor como "mensagem escolhida com intenção"); se bloqueado, o par em cinza com cadeado e um convite para desbloquear.
