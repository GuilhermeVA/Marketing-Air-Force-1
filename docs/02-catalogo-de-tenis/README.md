# Feature: Catálogo de tênis

**Criada em:** 2026-11-14

## Objetivo

Guardar no Supabase o catálogo de pares (cor, imagens, palavras-chave, texto de significado, raridade), editável sem mexer no código, já que o conteúdo final ainda será definido pelo grupo. É a base de dados para sorteio, closet e tela do tênis.
